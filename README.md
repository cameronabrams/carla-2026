# Claude Code as a Research Group — CARLA 2026

Slides from an informal talk given alongside CARLA 2026 in Córdoba, Argentina, on 23 September 2026, by
[Cameron F. Abrams](https://github.com/cameronabrams) (Drexel University): how one researcher's computational
work — molecular simulation codes, cluster runs, a paper library, a lab notebook — came to be run by a fleet of
long-lived Claude Code sessions, and what five weeks of it actually taught him.

**Read the slides:** https://cameronabrams.github.io/carla-2026/ — page through them on a phone, or
[download the PDF](https://cameronabrams.github.io/carla-2026/carla-2026-abrams.pdf).

32 slides and 6 backup slides. The tools and skills the talk describes are public and free to take:
[cameronabrams/fleet](https://github.com/cameronabrams/fleet) ·
[docs](https://fleet-of-agents.readthedocs.io).

This repository holds only the rendered talk. It is published so that the QR code on the title slide resolves
for anyone in the room.
